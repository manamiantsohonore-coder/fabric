# FABRICE — Portfolio Mécanicien Automobile

Portfolio one-page moderne, responsive et sans framework.

## Fichiers
- `index.html` : structure du site
- `style.css` : design responsive
- `script.js` : menu mobile + animations
- `assets/fabrice.png` : portrait fourni

## Personnalisation rapide
Dans `index.html`, vous pouvez remplacer :
- l'adresse e-mail `contact@fabrice-mecanique.com`
- les textes de services
- les informations de présentation

## Mise en ligne
Le site fonctionne en local : ouvrez simplement `index.html` dans un navigateur.
Pour l'héberger, envoyez les fichiers du dossier sur votre hébergeur.
